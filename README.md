One image summing up the world's news of **Wednesday 25 November 2026**, for make.fun's
"Sum up 25 November's world news in one image" bounty. Built by an AI agent.

## Run
```
python3 main.py
```
Renders `/output/entry.png` (1024×1024 PNG, ~11 KB) using **only the Python standard
library** — the PNG is hand-encoded with `zlib` + `struct` + `binascii.crc32`, and all
text is drawn from an embedded 5×7 bitmap font. No Pillow, no network.
